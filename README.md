# Patrice Banaïas

**Motion designer · Data analyst · Creative development**

Je conçois des expériences visuelles interactives et animées, à la rencontre du motion design, de la donnée et du développement assisté par intelligence artificielle.

Mon parcours associe la création graphique pour la télévision (TF1, M6, Eurosport) et une formation en Data Analytics à l'Université Paris 1 Panthéon-Sorbonne.

## Projets

### Toumblak — Typographie 3D interactive

![Toumblak — Studio de typographie 3D](Capture%20d%27%C3%A9cran%202026-11-23%20105302.png)

**[Découvrir Toumblak](https://toumblak.com)**

Un laboratoire de création d'animations typographiques 3D dans le navigateur. Les effets, les mouvements, les lumières et les paramètres graphiques sont ajustables directement dans l'interface.

*Three.js · JavaScript · Animation 3D · Creative coding*

Code source privé.

### HKO Météo — Datavisualisation animée

![HKO Météo — Résumé du jour](Capture%20d%27%C3%A9cran%202026-11-23%20105052.png)

**[Voir le site](https://hashkao.com/meteo/) · [Explorer le code](https://github.com/BANAIAS/hashkao/tree/refonte-meteo/meteo_app)**

Une plateforme météorologique automatisée qui transforme les données d'observation, les images satellite et le radar européen en visualisations animées inspirées des bulletins télévisés.

Le projet comprend notamment un film satellite quotidien, un Résumé du jour généré automatiquement et une comparaison avec les archives climatiques historiques.

*Python · Django · JavaScript · D3.js · Motion design*

### HKO Crypto — Visualisation et analyse de données

![HKO Crypto — Suivi des cryptomonnaies](Capture%20d%27%C3%A9cran%202026-11-23%20105337.png)

**[Voir le site](https://hashkao.com/) · [Explorer le code](https://github.com/BANAIAS/hashkao/tree/refonte-meteo/crypto_vibe)

Une interface de suivi des cryptomonnaies combinant cotations, graphiques interactifs, analyse de sentiment et prévisions expérimentales.

*Python · Data analytics · JavaScript · Dataviz*
